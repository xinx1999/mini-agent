# Mini Agent 项目说明

## 这是什么

一个能自己决定调用哪个工具的 AI agent，用 TypeScript 写成，**不依赖任何第三方框架**。

整个 agent 的核心是一个循环：调用模型，如果它要求调用工具，就执行工具并把结果回灌给模型，然后再调一次模型，直到模型不再要求工具为止。所有框架里那些复杂的概念，剥开都是这个循环。

## 代码结构

- `src/agent.ts` —— 核心循环。整个 agent 就是一个 for 循环，注释写满了
- `src/tools.ts` —— 工具集共五个：取时间、数学计算、列目录、检索本地文档、联网搜索
- `src/llm.ts` —— 与模型通信的唯一出口，配置全部走环境变量。流式解析和重试都在这里
- `src/trace.ts` —— 可观测性，记录每一步的 token 和耗时
- `src/memory.ts` —— 记忆，把完整对话历史存到磁盘
- `src/rag.ts` 与 `src/docs.ts` —— 文档检索，实现 RAG 的检索部分
- `src/search.ts` —— 联网搜索，抓 Bing 结果页并解析
- `src/compress.ts` —— 上下文压缩，历史超阈值时把早期对话交给模型总结
- `server.ts` —— HTTP 服务，把 agent 包装成网页可调的接口
- `web/index.html` —— 网页界面，单文件，原生 HTML/CSS/JS

## 怎么跑

命令行单次执行：`node --env-file=.env index.ts "帮我看看这个目录"`

命令行交互模式（多轮对话、历史落盘）：`node --env-file=.env index.ts`

网页版：`node --env-file=.env server.ts`，然后打开 http://localhost:3000

跑测试：`npm test`

看界面不想花 token：`npm run demo`（用假模型，回答是写死的脚本）

## 模型配置

改 `.env` 就能换模型，不需要动代码。任何兼容 OpenAI `/chat/completions` 的接口都能用，需要填三个值：`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。
